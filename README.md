# DEV@Deakin – C2 Deployment

## Project Description

DEV@Deakin is a web platform developed using React. It allows users to explore articles, tutorials, and portfolio content.

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Netlify Identity for authentication

## Features

- Home page
- Portfolio content
- Articles and tutorials
- Login page
- Sign-up page
- Navigation system

## Installation

1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.
